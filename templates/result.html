Presentation & Viva Reference Notes

Why YOLO11n?

YOLO11 is Ultralytics' newest model series. The 'n' (nano) variant has just ~2.6M parameters, making it lightweight enough for real-time CPU deployment in academic demos without needing dedicated GPU hardware.

Detection vs. Classification

Image Classification predicts what is in an image (one label). Object Detection identifies what and where (bounding box coordinates) for multiple simultaneous objects.

OpenCV Integration

OpenCV validates the decoded byte stream, verifies pixel arrays, and renders anti-aliased bounding boxes and contrasting label badges onto the original image matrix.
